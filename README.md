🌌 COSMOS — Astronomia & OBA
Site educativo de astronomia criado para ajudar estudantes a aprender sobre o Universo e se preparar para a Olimpíada Brasileira de Astronomia (OBA)
🚀 Sobre o projeto
O COSMOS reúne conteúdos de astronomia em uma experiência simples, visual e interativa.
✨ Recursos
•	🌍 Exploração do Universo
•	⭐ Conteúdos de astronomia
•	🧠 Estudos e desafios
•	🏆 Preparação para a OBA
•	📚 Recursos extras para estudantes
•	💎 Plano Premium por R$ 5,99
•	📱 Interface responsiva para celular, tablet e computador
💎 Recursos Extras
O plano de Recursos Extras custa R$ 5,99 e oferece materiais adicionais de estudo.
Observação: o sistema de pagamento ainda precisa ser conectado a um meio de pagamento, como Pix ou cartão.
🌠 Objetivo
Tornar o estudo de astronomia mais divertido, acessível e interessante, ajudando estudantes a desenvolver conhecimentos para a OBA.
